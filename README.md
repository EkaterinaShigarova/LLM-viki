# LLM-viki

Научная база знаний по экологическому мониторингу озера Байкал и Байкальской природной территории (БПТ). Проект выполняется в рамках исследовательской работы автора в ИДСТУ СО РАН; официальное одобрение или публикация институтом не заявляются.

**Codex выступает агентом, который изучает источники и поддерживает постоянную связанную Markdown-базу для людей и других ИИ.** Отдельная Qwen, другой локальный модельный сервер, обучение сети или платный API не нужны. [Методика Карпати](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) прочитана целиком; [соответствие архитектуры](docs/KARPATHY_ALIGNMENT.md).

Основной процесс: **PDF → подробные конспекты разделов → тематические статьи → связи, индексы и проверка источников**. Машинное извлечение и поиск помогают агенту, но не подменяют чтение/синтез.

## Что фактически имеется

Сохранены **11 PDF /3878 технически обработанных страниц**: десять докладов за 2015–2024 и официальный общероссийский обзор за 2025, опубликованный в 2026. [SOURCES.md](SOURCES.md) содержит адреса, SHA256 и статусы происхождения. Целевые 2003–2026 не означают наличие всех лет.

В текущей Wiki **40 тематических аналитических статей** и **106 подробных конспектов выбранных подразделов всех 11 документов**. Конспекты затрагивают 269 физических страниц; это не полное содержательное покрытие этих страниц, разделов или всего корпуса. [Аудит](docs/CORPUS_AUDIT.md) и [матрица](datasets/coverage_matrix.csv) явно показывают пробелы.

[Голомянки: адаптация и кислородная гипотеза](docs/GOLOMYANKA_REVIEW.md).

[Байкальский омуль: четыре доклада](docs/OMUL_REVIEW.md).

[Донные отложения и притоки Селенги](docs/SEDIMENT_TRIBUTARY_REVIEW.md): литотипы, ПАУ/БП и раздельные речные створы.

[Температура, геохимия и качество воды](docs/WATER_GEOCHEMISTRY_REVIEW.md): исток Ангары, озёрные разрезы и створы Селенги.

[Гидрологическое пополнение](docs/HYDROLOGY_REVIEW.md): основные годовые подразделы 2015–2024, водный баланс, весенние ледовые фазы и источниковые ограничения таблиц.

Сохранены **168 ранее сверенных наблюдений**, 17 отдельных источниковых карточек, научные цитаты, ограничения и три прежних кандидата дополнений. Новые цифры конспектов не добавляются автоматически в observations. Обычная публикация агентом и точная цитата не являются научной экспертизой.

## Каталоги

| Путь | Назначение |
| --- | --- |
| data/raw/ | Неизменяемые оригиналы по SHA256; локально, вне Git |
| data/processed/ | Готовые страницы JSON, машинные Markdown/HTML, таблицы, изображения, OCR; вне Git |
| `wiki/notes/<source-id>/` | Содержательные конспекты отдельных разделов и индекс документа |
| wiki/syntheses/ | Связанные тематические статьи по нескольким источникам |

## Локальный запуск

Python 3.11+, Git, по желанию VS Code. Команды из папки проекта:

```bash
git clone https://github.com/EkaterinaShigarova/LLM-viki.git
cd LLM-viki
git switch feat/baikal-llm-wiki
python -m venv .venv
```

Активируйте окружение: Linux/macOS `source .venv/bin/activate`; Windows PowerShell `.\.venv\Scripts\Activate.ps1`. Без активации можно использовать полный путь к Python окружения.

```bash
python -m pip install -e ".[test]"
python -m baikal --help
python -m baikal query "качество воды"
python -m baikal lint
python scripts/check_scientific_data.py --require-local
python scripts/check_knowledge.py --require-local
python -m unittest discover -s tests -v
```

В чистой копии Git нет PDF, результатов страниц, индекса и прежних локальных архивов. Для проверки публичных реестров используйте команды проверки **без** require-local; отчёт не должен выдавать их за чтение оригиналов. Сохраняйте data отдельно в резервной копии. Подробная финальная инструкция Windows/VS Code остаётся задачей.

## Новые источники и поддержка

Проверить происхождение/дубликат → зарегистрировать → ingest с продолжением → прочитать разделы → написать подробные конспекты → синтезировать статьи → обновить связи и источниковые реестры → lint/журнал/commit. Команда ingest выполняет технический этап, **не самостоятельное содержательное чтение всего PDF**. Точные пользовательские шаги и проверенные команды — в памятке, правила для агента — в [AGENTS.md](AGENTS.md).

Неизменяемые исходники, физические страницы, методы/единицы/годы и неопределённости обязательны. Документ на Drive пока остаётся mirror_unverified без независимой проверки официального экземпляра. Числовые тренды требуют сопоставимости.
