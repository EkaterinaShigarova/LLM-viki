# Описание изменений для Pull Request

Изменения должны объяснять конкретное научное пополнение: какие разделы законспектированы, что добавлено в Wiki, какими страницами подтверждено, какие ограничения сохранены. Указать проверки и сохранность исходников/observations/заметок.

Рабочая ветка feat/baikal-llm-wiki репозитория EkaterinaShigarova/LLM-viki. Не сливать main автоматически. Обычная публикация агентом не подменяет экспертную рецензию; новые значения не становятся observations без отдельной сверки.
