Это научная база знаний об экологическом мониторинге Байкала и БПТ. Она помогает находить не только число, но и его смысл: что измеряли, где, когда и каким способом. Проект связан с исследовательской работой автора в ИДСТУ СО РАН; одобрение институтом не заявляется.

## Кто создаёт знания

Codex читает государственные доклады, готовит подробные конспекты разделов и объединяет их в тематические статьи. Программы помогают получать PDF, извлекать текст/таблицы и проверять ссылки. Их успешная работа ещё не означает, что весь документ изучен.

Отдельная Qwen не нужна. В проекте нет необходимости запускать собственную языковую модель. Другой ИИ сможет читать готовую Wiki так же, как человек, и проверять её источники.

## Google Drive, GitHub и оригиналы

Google Drive — место передачи исходных докладов. Наличие файла там не означает официального подтверждения его версии. GitHub хранит тексты Wiki, код, небольшие данные и историю изменений. Рабочая ветка — feat/baikal-llm-wiki в репозитории EkaterinaShigarova/LLM-viki.

Оригинальные 11 PDF лежат локально в data/raw/. Имя — длинная контрольная сумма SHA256. По ней файл можно найти через config/sources.json. Не переименовывайте и не редактируйте PDF. Десять докладов относятся к 2015–2024; обзор за 2025 опубликован в 2026. Доклады всех лет 2003–2026 ещё не собраны.

Папка data не хранится в GitHub из-за размера и временных файлов. Её нужно отдельно резервировать. В `data/processed/<sha256>/markdown/` находятся машинные постраничные тексты; в pages/*.json — текст, строки таблиц и сведения об изображениях. Это не те же подробные конспекты, которые пишет агент в Wiki.

## Как проверить утверждение

1. Откройте статью через главный каталог. Найдите ссылку рядом с утверждением.
2. Перейдите в подробный конспект, чтобы понять год, территорию, единицу и ограничения.
3. Откройте ссылку source-id:pN на страницу документа. На ней можно найти оригинал PDF.
4. N — физическая страница, которую показывает просмотрщик PDF. Напечатанный на листе номер может отличаться.
5. Проверьте подпись таблицы, столбец, период, единицу, территорию и примечание. Среднее не равно максимуму; прочерк не означает ноль; лимит не равен выполненному действию.
6. Посмотрите открытые вопросы. Если источники расходятся, оба сообщения сохраняются, а не выбирается удобное число.

Год доклада не всегда является годом наблюдения. Например, в обзоре за 2025 есть строки 2024; публикация 2026 не переносится на эти измерения. Точная цитата и работа программы не заменяют научную рецензию.

В новой таблице Кабанска `min` означает минимум, `max` — максимум, `mean` — среднее. `previous` относится к 2023 году, `current` — к 2024. `printed_mean_change` — напечатанная разность средних. Это помогает читать исходную таблицу; её строки не становятся автоматически частью 168 observations.

В таблице притоков `river` — река, `station` — пункт, `value` — максимум, `unit` — единица, `dates` — даты. `printed_pdk_multiple` сохраняет кратность ПДК ровно как в докладе; это не обещание её безошибочности. В `source_issue` отмечены две спорные записи Модонкуля. В таблице ПАУ/БП `minimum`, `maximum`, `mean` — минимум, максимум, среднее; единица нг/г с.о. относится к донному материалу, не к воде. Эти таблицы не пополняют 168 observations.

## Как искать по сохранённой Wiki

В установленном окружении можно выполнить `python -m baikal query "судовые воды"`. Поиск учитывает совпадения слов в заголовке и отдаёт предпочтение содержательным статьям и конспектам перед длинными машинными страницами при сопоставимой релевантности. Он не создаёт нового научного вывода. Через каталог можно читать базу и без запуска программы.

## Как будут добавляться новые документы

Сначала проверьте титул, ведомство, версию и отсутствие дубликата в SOURCES.md. Не подставляйте год из имени файла. Для нового официального HTTPS-адреса существуют add-source и ingest. Перед любыми изменениями сохраните резервную копию рабочей папки с data.

В установленном окружении из папки проекта можно безопасно посмотреть реальные параметры:

```bash
python -m baikal add-source --help
python -m baikal ingest --help
python -m baikal status
```

Регистрация принимает только настроенные официальные домены. Не используйте случайную ссылку вместо государственного документа. Затем Codex должен проверить источник, использовать готовые страницы или выполнить обработку только нового PDF, написать конспекты и обновить знания. Нажатие «добавить файл» не означает автоматическую достоверную статью.

Полезная просьба агенту: «Изучи новый доклад по разделам, составь подробные конспекты, найди все релевантные темы, обнови Wiki и матрицу, проверь утверждения и сохрани неопределённости». Статьи без достаточных доказательств остаются исследовательской очередью.

## Поиск и проверка базы

Подготовка Python описана в [README](../README.md). В терминале из папки проекта:

```bash
python -m baikal query "качество воды"
python -m baikal lint
python scripts/check_scientific_data.py --require-local
python scripts/check_knowledge.py --require-local
```

Query ищет в сохранённой Wiki и не выдаёт новый научный вывод. Lint проверяет связи и договорённости. Последние две команды требуют готовую data и проверяют реальные исходные страницы; без require-local можно проверить публичные реестры, но это не чтение отсутствующего оригинала. Они не запускают модели и не выполняют OCR заново.

Не добавляйте новые числа в observations без сверки; не стирайте неизвестные значения, исходные противоречия, заметки и историю. Не считайте количество обработанных страниц числом содержательно изученных страниц. Не исправляйте исходный PDF и не делайте вывод о причинности только по совпадению чисел.

## История и небольшой словарь

История изменений — вкладка Commits на GitHub и [журнал Wiki](../wiki/LOG.md). Итоги тестов и текущие пробелы — PROGRESS.md и docs/REMAINING.md. Git хранит прежние версии, но локальную data нужно резервировать отдельно.

- **LLM Wiki** — постоянная связанная база, которую поддерживает языковой агент; это не требование устанавливать отдельную модель.
- **Codex** — агент, который читает документы и ведёт базу.
- **Markdown** — обычный текст с заголовками и ссылками, файлы .md.
- **CSV** — таблица в текстовом файле; открывается в Excel/LibreOffice с кодировкой UTF-8.
- **JSON** — структурированный текстовый реестр, удобный для программ и ИИ.
- **Commit** — сохранённый этап изменений в Git.
- **SHA256** — контрольная сумма файла для проверки его точной версии.
- **OCR** — распознавание текста изображения страницы; ошибки возможны.
- **Wiki lint** — проверка целостности базы; она не подтверждает истинность всех измерений.

Это рабочая памятка. Отдельные окончательные Word/PDF, справочник основных таблиц и подробная инструкция Windows/VS Code ещё требуют подготовки.

Таблицы омуля — отдельный перенос первоисточников, а не пополнение 168 проверенных наблюдений. Спорный вылов 2023 сохранён как 90 и 80 т по разным докладам. Чтобы проверить число, смотрите report_year(доклад), year(год показателя), source_id, source_sha256 и pdf_page(физическая страница).

## Гидробиология 2021 и частично восстановленная обработка
