## Постоянный цикл

Источник → проверка происхождения/версии → извлечение с продолжением → подробные конспекты разделов → тематический синтез → связи и индексы → проверка/журнал.

Каждый следующий сеанс выбирает реальные пробелы матрицы, обрабатывает разделы до содержательного результата и отмечает точный объём чтения. Цель — максимальная полезная полнота без пустых статей. Не объявлять весь доклад проанализированным по факту обработки страниц. Научная рецензия, уточнение методик и получение отсутствующих источников идут отдельными задачами. Исторические планы и эксперименты доступны в Git до коммита переработки.
